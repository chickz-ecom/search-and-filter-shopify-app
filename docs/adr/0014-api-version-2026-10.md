# ADR 0014 (D14): API version 2026-10 một chỗ

- Trạng thái: Accepted (2026-10-26)
- Nguồn: docs/02-PLAN.md mục 2, docs/01-RESEARCH.md

## Bối cảnh
Collection model mới (2026-07) bị ẩn với version cũ; App Store chặn version sắp deprecate trong 90 ngày.

## Quyết định
`apiVersion` cấu hình một chỗ (`app/shopify.server.ts` + `app/lib/shopify/api-version.ts`), TOML `api_version = "2026-10"`.

## Hệ quả
Nâng version theo quý; chỉ GraphQL Admin API.
